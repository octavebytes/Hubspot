# HubSpot CTI Connector — Documentation

Public documentation for the Octave Bytes HubSpot CTI Connector: a Chrome extension and customer-hosted connector that integrates **AWS Connect CCP** with **HubSpot CRM** for contact-center agents (screenpop, click-to-dial, WhatsApp messaging, activity logging, and call transcripts).
