## What is the HubSpot CTI Connector?

A Chrome extension and a connector deployed in the customer's own AWS account bring AWS Connect voice, chat, and WhatsApp into HubSpot CRM — screenpop, click-to-dial, wrap-up dispositions, and automatic activity logging, in one workspace for contact-center agents.
